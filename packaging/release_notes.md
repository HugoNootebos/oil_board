## Install

**Mac**: download `OIL-mac-arm64.zip` (Apple Silicon: M1 and later) or `OIL-mac-intel.zip` (older Intel Macs), unzip it and drag **OIL** into Applications. The first time, macOS blocks it because it isn't from the App Store. Open it once, then go to System Settings › Privacy & Security and click **Open Anyway**.

**Windows**: download and run `OIL-Setup.exe`. If Windows shows "Windows protected your PC", click **More info › Run anyway**.

**Linux** (64-bit Intel/AMD; Ubuntu 20.04, Debian 10, Fedora 29 or newer): download `OIL-linux.tar.gz`, unpack it and run `./install.sh` in the folder `OIL` in a terminal. OIL then appears in your applications menu. To remove it: `~/.local/opt/OIL/install.sh --uninstall`.

## Updates

New versions of the game come in with the **Update** button in the main menu. You don't need to download the app again. Your saved games stay on your own computer and an update never changes them.

## Online play

**Online Game › Host** opens a game that others see under **Online Game › Join**. One computer can have several players, and the others join from their own computer. Everyone sees the host's screen, and each player clicks with their own mouse or controller when it's their turn. The first time you host, allow the incoming connections if your computer asks.
